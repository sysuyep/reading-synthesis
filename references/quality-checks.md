# 电子书质量检查

## EPUB

检查 ZIP 完整性、`container.xml`、OPF、manifest、spine、导航目录、缺失资源、空章节、正文字符数、图片数量和加密声明。

高风险信号：

- ZIP 损坏或 OPF 缺失。
- 大量 spine 文件为空。
- 只有图片、几乎没有可搜索文字。
- 缺少目录或章节顺序异常。
- `encryption.xml` 表明正文被 DRM 加密。
- 乱码、重复章节、广告和来源水印占比明显。

## PDF

使用 `pdfinfo`、`pdftotext` 和 `pdffonts` 检查页数、元数据、文字层、每页文字量和字体。当前环境缺少 `qpdf` 时，不把“未运行 qpdf”误报为文件损坏。

高风险信号：

- 平均每页可提取文字极少，疑似扫描版。
- OCR 出现大量替换符、控制字符或异常断行。
- 页数异常、目录缺失或大量空页。
- 加密导致无法提取文字。

## AZW3

需要 Calibre 的 `ebook-meta` 与 `ebook-convert`。缺少依赖时请用户改给 EPUB/PDF，或征得同意后安装 Calibre。检测到 DRM 时停止，不绕过。

## 质量等级

- `excellent`：结构完整、正文丰富、目录可用、无加密和明显异常。
- `good`：可稳定阅读与检索，存在少量结构缺陷。
- `fair`：可以使用，但上下文和章节定位可能不稳定。
- `poor`：正文不足、损坏、严重 OCR 问题或无法可靠定位。
- `unreadable`：无法提取或受 DRM/密码保护。

质量分数只用于候选排序。版本匹配度高但质量一般的文件，可能仍比高质量的不同译本更适合作为划线上下文。
